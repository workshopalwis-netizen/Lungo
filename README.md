# LUNGO Sri Lanka ☕ | Premium Specialty Coffee Website

A modern, responsive, luxury coffee brand website created for **LUNGO Sri Lanka**. Designed with an international specialty-coffee aesthetic combining deep espresso tones, warm cream backgrounds, caramel accents, elegant typography, and authentic brand photography.

## 🎨 Design System

| Color Role | Hex Code | Purpose |
|---|---|---|
| **Espresso Brown** | `#2B1B16` | Hero backgrounds, header scroll state, primary dark accents |
| **Coffee Brown** | `#5C3828` | Headings, secondary dark layers, badge strokes |
| **Caramel Accent** | `#B9824B` | CTAs, glows, icons, active navigation indicators |
| **Cream** | `#F6F0E6` | Primary soft background for cards and daytime reading |
| **Warm White** | `#FFFCF7` | Card surfaces and high-contrast text |
| **Dark Charcoal** | `#201A17` | Footer and deep contrast layers |

## ☕ Website Architecture & Sections

1. **Sticky Navigation Bar**:
   - High-contrast LUNGO insignia vector & typography
   - Navigation links: Home, Our Coffee, About Us, Gallery, Contact
   - Direct Call shortcut (`+94 70 503 2889`)
   - Prominent *"Explore Our Coffee"* CTA button
   - Responsive mobile navigation with animated hamburger drawer

2. **Hero Section**:
   - Full-width cinematic coffee visual with warm espresso overlay
   - Headline: *“Every Cup Tells a Story.”*
   - Supporting text: *“Discover the rich aroma, smooth taste, and timeless pleasure of coffee with LUNGO.”*
   - Direct CTAs: *"Discover Our Coffee"* and *"Contact Us"*
   - Micro-stats pill bar & subtle scroll indicator

3. **Our Coffee Section**:
   - Headline: *“Made for Coffee Moments.”*
   - Brand experience categories:
     - **Rich & Bold** — For those who appreciate deep coffee flavors.
     - **Smooth & Balanced** — A smooth, satisfying coffee experience.
     - **Your Daily Ritual** — Make every coffee break special.
   - Hover zoom effects, atmospheric badges, and experience notes (with strict adherence to brand honesty: no invented prices, origins, or certifications).

4. **Brand Story Section**:
   - Headline: *“More Than Coffee. It's a Feeling.”*
   - Split layout with editorial copy and large imagery of official LUNGO stacked cups
   - 4 brand pillars: *Flavor*, *Quality*, *Comfort*, *Ritual*

5. **Coffee Experience (Gallery & Showcase)**:
   - Editorial grid showcasing official LUNGO branded ceramic and takeaway cups, golden crema extraction, whole roasted beans, and brewing craft
   - Interactive category filter tabs
   - Interactive Lightbox modal preview with full-screen zoom and editorial descriptions

6. **Why Choose LUNGO?**:
   - 4 honest brand pillars:
     1. A Passion for Coffee
     2. Memorable Coffee Experiences
     3. A Premium Visual Identity
     4. Celebrating Everyday Moments

7. **Social Media Hub**:
   - Dedicated high-engagement cards with official brand handles
   - Direct links to Instagram (`@lungosrilanka`) and Facebook
   - Visual feed preview grid

8. **Contact Section**:
   - Headline: *“Let's Talk Coffee.”*
   - Direct contact cards (Phone, Email, Location)
   - 4 instant action buttons (*Call Us*, *Email Us*, *Follow on Instagram*, *Visit Facebook*)
   - Interactive validated contact form (*Full Name*, *Email*, *Subject*, *Message*)
   - Transparent integration feedback banner explaining client-side validation and providing pre-filled email dispatch

9. **Footer**:
   - Deep espresso palette
   - LUNGO logo, brand overview, quick links, contact info, social links
   - Copyright notice: *“© 2026 LUNGO Sri Lanka. All rights reserved.”*

10. **Floating Controls**:
    - Verified floating WhatsApp quick chat button (`+94 70 503 2889`)
    - Smooth scroll-to-top floating control

## 💻 Tech Stack

- **Framework**: React 18 + TypeScript
- **Styling**: Tailwind CSS
- **Bundler**: Vite 5
- **Icons**: Lucide React
- **Typography**: Google Fonts (Cinzel, Playfair Display, Plus Jakarta Sans)

---

## 🚀 Running the Project

Start the development server:
```bash
./start.sh
```
or
```bash
npm run dev
```

Build for production:
```bash
npm run build
```

Preview production build:
```bash
npm run preview
```
